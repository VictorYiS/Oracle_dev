# Oracle

[English](README.md) · **中文**

一个叙事经营游戏：一座可以把一切都交给 AI 的小城。你是坐在城中窗口后面的"译者"。神谕好用得惊人，好用到你渐渐不再亲自去看。

- 在浏览器里玩：https://victoryis.github.io/Oracle_dev/
- 当前阶段：P2，窗口与街道。你可以在城里走动，在窗口办案、做决定，对神谕的建议可以直接采信，也可以去核对。神谕更深的机制会在之后的阶段登场。

## 怎么玩（P2）

1. 点**新游戏**，再依次点**读晨报**和**开窗**。只有白天时间才会流动。
2. 你从窗口开始。按 **E** 打开窗口。访客会来排队：读他们的文件（每份都写明来源和日期），查办事规程，然后盖章决定，或者**采纳**神谕的建议。
3. 没核对就采纳的东西，会放进你的**待核事项**托盘，并写明怎么核：亲自去看，或者在窗口调阅原件。
4. 离开窗口走一走：**A / D**、**← / →** 或点地面。在台阶、桥、巷口和门边，**↑ / W** 向里走，**↓ / S** 返回。每条通道都要花时间，你出门的时候，队伍会越排越长。
5. **看 ≠ 去。**站在书柜前，滚轮↑ 或 **F** 仔细看，滚轮↓ 或 **Esc** 回到人物视角。只有指定物件附近可以缩放；到城里的别处需要走过去。
6. 你从没见过的楼，是神谕按记录画的。你见过的楼，画的是你记得的样子，记忆会褪色，也不会自己更新：想知道变了什么，就回去看。

全部按键和手机上的按钮见 [guide/controls.zh-CN.md](guide/controls.zh-CN.md)。**设置**里有**减少动画**开关。

## 语言

游戏跟随浏览器的语言，也可以在标题画面或顶栏切换。目前支持英文和简体中文；你的语言暂不支持时显示英文。

## 开发

需要 Node 22 以上。

```bash
npm ci
npm run dev          # 本地开发
npm run check        # 类型、lint、单测、引擎中立性、界面文案、剧本包校验
npm run build        # 生产构建（含首包体积预算）
npm run e2e          # 端到端测试：Chromium、Firefox 和手机尺寸（先 build）
npm run smoke        # 每个剧本包无头跑 30 天
npm run determinism  # 两次 100 天的运行和一次重放，必须逐日一致
npm run bench        # 30 个游戏日的耗时
npm run gallery      # 把每个建筑配方画出来：dist-gallery/ 和一份哈希清单
```

## 剧本包

游戏内容都在 `scenarios/` 里，引擎不认识任何剧本专有名词。`scenarios/interpreter/` 是默认剧本"译者"。新剧本可以继承它，只写出不同的部分：

```yaml
# scenarios/my-story/scenario.yaml
id: my-story
version: 0.1.0
engine: "0"
extends: interpreter
title: "@scenario.title"
```

剧本包描述地点（场景、组成场景的层、层与层之间的通道）、建筑和住在里面的人、机构和它们的记录、窗口受理的案件类型，以及一切怎么画：风格包、建筑配方、部件和手绘地标。视觉编译器把这些变成画面；同一个种子永远画出同一栋楼。`tests/fixtures/scenarios/accept-mini/` 是一个小例子：从对岸拿掉三栋房子，并给一个风格包换了颜色。也可以在游戏里从文件夹或 `.zip` 导入剧本包。

每个剧本包都要声明自己支持的语言（`languages: [en, zh-CN]`，第一个是回退语言），文案放在 `locale/<语言>.yaml`。`npm run validate` 会检查所有剧本包，报错时给出文件和字段，包括走不到的地点、某种语言缺了哪条文案。
