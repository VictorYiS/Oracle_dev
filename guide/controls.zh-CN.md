# 操作说明

[English](controls.md) · **中文**

你是"译者"。你坐在街边的窗口后面，替来办事的人做决定；你也可以离开窗口，亲自去看。时间只在白天流动。

## 一天

- **黎明**和**上午**：一切静止。按**回车**（或顶栏的按钮）继续。
- **白天**：时钟在走。**空格**暂停或继续，**1 / 2 / 3** 切换速度（×1、×2、×4），**T** 让一小时过去。
- **黄昏**：白天批下的工程在这时施工；还在窗口排队的人回家。然后是夜间，再到第二天黎明。

## 走动

- **A / D** 或 **← / →**：在你所在的这一层上走（街道、河岸、对岸、屋内）。
- **点地面**走过去；点你这一层上的东西，会走到它跟前并使用它。
- **↑ / W**：沿附近的通道向里走，包括台阶、桥、巷子和门。**↓ / S** 沿通道向外走。提示会写出通道名和对应按键。
- **E**：使用身边的窗口或告示。
- 手机上：按住 **◀ ▶** 走动，点 **↑ ↓** 走通道，**E** 使用物件。

走路要花游戏时间，每条通道也是：下河的台阶、人行桥、巷子、门。

## 看 ≠ 去

街道是一座纸面剧场：一张张景片竖在不同的深度上。建筑的实际尺寸保持固定，镜头靠近时通过透视连续变大；室内使用更近的取景，镜头跟随人物。

- 站在登记处或 17B 的书柜前，**滚轮↑** 或 **F** 仔细看。**人还在原地。**
- **滚轮↓** 或 **Esc** 回到人物视角。观察时按 **↑ / ↓** 也会先退出观察，再次按键才能通行。
- 手机上：**⊕** 仔细看，**⊖** 返回，只有可以使用时按钮才可用。
- 在普通街景中滚轮不移动镜头；只有指定物件附近可以缩放。

左上角始终写着*人*在哪一层、*镜头*在哪一层。点远层的东西不会有任何效果：要到那里，得走过去，走通道。

## 亲见、记忆、神谕的画

- 你从没亲眼看过的楼，由神谕按机构的记录来画：干净、苍白、发光。记录变了，画也跟着变。
- 走到楼跟前，你看到的是它真实的样子，用墨线画。
- 走开以后，它停在你上次看到的样子，是一段慢慢褪色的记忆。城市在你背后照常变化，你的记忆不会自己更新。回到那里，如果有什么变了，它会重画，事件流里会写明哪里不一样。

## 窗口

在窗口按 **E**。白天会有访客来排队。

- **文件**：访客的申请表，以及每个相关机构的摘录。每份文件都写明来源和日期。打开一份可以看特写。
- **办事规程**：这一类案件的规矩。
- **神谕建议**：一句摘要和一个动作。**采纳**就照它的建议办；也可以自己盖章决定。
- 需要施工的决定（接电、维修）在黄昏执行。

## 待核事项

采纳了建议以后，神谕默认成立的事会放进你的托盘（按 **P**，或点右上角的标签），并写明怎么核：亲自去看，或者在窗口调阅原件（要等一会儿）。核过以后会标出对还是不对。无论对错，都不会因此扣你什么。

## 设置

顶栏的**设置**里有**减少动画**：镜头直接切换、不再移动，也没有闪烁和晃动。**?** 列出全部按键。
